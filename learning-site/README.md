# 「Webを支える技術」学習サイト

HTTP・URI・HTML・REST を、IT初級者向けに「技術体系の全体地図」として整理した静的学習サイトです。
書籍『Webを支える技術 — HTTP、URI、HTML、そしてREST』(山本陽平 著、技術評論社、2010年)の構成をベースに、
2026年現在の最新動向(HTTPS 必須化、HTTP/2・HTTP/3、JSON、fetch、SPA、OpenAPI など)をコラムで補足しています。

## 閲覧方法

ビルド不要・外部依存なしの静的サイトです。`index.html` をブラウザで開くだけで閲覧できます。

```bash
# 例: ローカルサーバで開く場合(任意)
npx serve learning-site
```

## サイト構成

| ファイル | 内容 | 書籍の対応箇所 |
|---|---|---|
| `index.html` | 全体像 — 4 キーワードの位置関係の地図(たとえ話・スタック図・比較表) | 第1部 Web概論 |
| `web.html` | Webとは — 歴史・ハイパーメディア・クライアント/サーバ | 第1部 Web概論 |
| `uri.html` | URI — リソースの住所、構文分解、クール URI | 第2部 URI |
| `http.html` | HTTP — メソッド、ステータスコード、ヘッダ、ステートレス性 | 第3部 HTTP |
| `html.html` | HTML — リソースの表現、ハイパーメディア、JSON との比較 | 第4部 ハイパーメディアフォーマット |
| `rest.html` | REST — アーキテクチャスタイル、6 つの制約、REST API 実例 | 第1部第3章ほか |
| `ajax.html` | Ajax — fetch のコードと実際の HTTP メッセージの対応、CORS、SPA | 第4部(現代補完) |
| `api-design.html` | API設計 — 架空の書店 API を題材にした設計手順 | 第5部 Webサービスの設計 |
| `glossary.html` | 用語集 — 各用語が「どの層の話か」を併記した索引 | — |
| `style.css` | 共通スタイル(ライト/ダークテーマ対応、外部 CDN 不使用) | — |

## 設計方針

- **全体俯瞰を最優先**: 各用語が体系のどこに位置するかを、トップページの地図と各ページ冒頭のミニマップで常に提示する
- **実例主義**: 生の HTTP リクエスト/レスポンス、HTML・JavaScript・JSON のソースコード例を必ず添える(ハンズオンは不要)
- **自己完結**: 外部 CDN・画像・フォントを参照せず、HTML + CSS のみで完結する
